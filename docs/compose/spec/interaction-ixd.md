# TeamSpeak Web 全站交互设计方案（IXD）

## Report

## [S1] Problem

视觉已是 Linear 风格，但交互仍停留在「能用」层，对照官方 TS3 客户端与现代 VoIP 工具（Discord / TeamSpeak 6）有明显缺口：

1. **首屏无引导**：进来就是一张表单 + 两块空面板，新用户不知道先做什么。
2. **连接后表单仍占位**：左栏 288px 里「连接表单」已失效却继续占用首屏，音频设置被挤到下方需要滚动。
3. **状态反馈分散**：`error-box` / `ok-box` / 顶栏 badge / 重连提示各说各话，没有统一通知层。
4. **语音状态不可感知**：自己是否在上行、谁在说话、PTT 是否按住，都只有小圆点/小字提示。
5. **右键菜单浅**：音量只有 4 个固定档位，无二级菜单、无滑杆。
6. **多开信息丢失**：切到别的标签后，新消息/进出/Poke 完全无感知。
7. **无键盘体系**：除 PTT 与 Enter 发送外无快捷键，重度语音用户手离不开键盘。
8. **频道树缺高频操作**：无搜索过滤、无「回到我的频道」、双击加入尚在 spec 未落地。

## [S2] Design

模式：**convention mode**（VoIP 工具）— 不改三栏信息架构，只补交互层。所有动效 ≤150ms，尊重 `prefers-reduced-motion`。

---

### A. 首屏与连接流程

**A1. 未连接：引导式首屏**

- 左栏保持连接表单（它就是首页），中/右两栏合并显示一个 **welcome-hero**（样式 token 已存在）：
  - 标题「在浏览器里连上 TeamSpeak」
  - 三步说明：① 填地址昵称 → ② 点击连接 → ③ 允许麦克风权限
  - 若 `DEFAULT_HOST` 已预填 → hero 改为「一键加入 \<服务器名\>」大按钮（primary），点击直接 `connectTab`
- 表单校验内联化：地址/昵称为空时点「连接」，对应输入框描红 + 抖动 200ms + 框下 12px 错误文案，**不再用底部 error-box**。

**A2. 连接中 / 重连中**

- 连接按钮变 loading 态（spinner + 「连接中…」），整块表单禁用。
- 自动重连从角落文案升级为**顶部细进度条**（Linear deploy 条样式）：全宽 2px，primary 色，indeterminate 动画；悬浮显示「第 2/5 次重连，3s 后重试 · 点击取消」。
- 5 次失败后进度条变 err 红色静态条：「重连失败 · [重试] [放弃]」。

**A3. 已连接：表单折叠**

- 连接成功后左栏「连接」section 自动折叠成一张**会话卡**：
  - 服务器名（14px 600）· `host:port`（11px dim）· 延迟占位
  - 右侧一个「断开」ghost 按钮
  - 点击卡片可展开回完整表单（编辑需先断开，沿用现有 disabled 逻辑）
- 音频 section 上移成为首屏，VOX 阈值/PTT 键等关键设置一屏可见。

---

### B. 频道树交互

**B1. 单击选中 · 双击加入**（落地 `double-click-ns` spec）

- 单击频道行 = 选中（surface-3 底色，不跳转）；有子频道时再点折叠箭头折叠。
- 双击 = 加入频道。hover 时行尾浮现 hint「双击加入」（11px faint，仅未连接该行时显示）。
- 我所在的频道行：左侧 2px talk 绿竖条（替代现在的 accent 竖条——绿=语音语义，紫=焦点语义，两者分开）。

**B2. 说话者高亮增强**

- 说话成员整行泛绿光：背景 `rgba(61,216,140,0.06)` + 圆点呼吸（已有点保留）+ 昵称色 `--talk`。
- 静音/闭麦图标从 emoji 换成统一 12px 线性图标（减少视觉噪音）。

**B3. 频道过滤**

- 频道面板标题行右侧加一个搜索图标按钮，点击展开过滤输入框（自动聚焦，Esc 收起）：
  - 输入即过滤：匹配频道名/成员昵称，命中的父链自动展开，命中文字 primary 高亮。
  - 空结果显示「无匹配频道」。
- 纯前端过滤，无协议改动。

**B4. 回到我的频道**

- 当我滚动离开自己所在频道时，频道面板底部浮出 pill 按钮「↓ 回到我的频道」，点击平滑滚动定位。

---

### C. 语音状态条（新增底部全局组件）

在 `.main` 下方新增 40px **语音状态条**（连接后显示，未连接隐藏）：

```
[🎙 开麦·VOX]  [====电平====|阈值]  [按住空格说话]   [张三 正在说话]        [静音] [ Deafen ]
```

- 左：当前发送模式 + 电平条（VOX 模式下带阈值刻度线，超阈值段变绿）。
- 中：情境提示——PTT 未按时显示淡灰「按住 空格 说话」；按住时整条泛绿「上行中」。
- 右：当前说话者轮转显示（最多 2 人，超出「+N」）。
- 最右：**静音 Mic** 与 **Deafen（闭麦+静音输出，TS 用户刚需，当前缺失）** 两个图标按钮，激活态描红。

---

### D. 右键菜单升级

- 分组 + 分隔线：沟通（私聊 / Poke / 耳语）｜音量｜其他（复制昵称）。
- 「加入耳语目标 / 耳语其所在频道」收入「耳语 ▸」二级菜单。
- 音量改为**内嵌滑杆**（0–150%，实时显示百分比，松手才 `setClientVol` 防抖 100ms），保留 0/50/100/150 快捷刻度点。
- 菜单打开时首个选项自动聚焦，↑↓ 导航、Enter 执行、Esc 关闭（当前只能鼠标）。
- 对自己右键：仅显示「复制昵称 / 设置 away」等可用项，禁用项置灰而非隐藏。

---

### E. 聊天与通知

**E1. 未读体系**

- 非活动服务器标签收到消息 → 标签名右侧圆点（pm/Poke 用 primary 紫，普通频道消息用 faint 灰）。
- 侧栏「事件」tab 同理显示未读计数 badge。
- 切回即清零。

**E2. 聊天滚动**

- 新消息到达时若用户已上翻 → 不自动滚动，底部浮「↓ 新消息」pill（带计数），点击回底。
- 贴底时才自动跟随滚动。

**E3. 统一 Toast（新增通知层）**

- 右上角 toast 栈（最多 3 条，4s 自动消失，hover 暂停）：
  - `success` 已连接 / `info` 有人进出（可关）/ `warn` 断线重连 / `err` 协议错误。
- 现有 `error-box`/`ok-box` 全部迁移到 toast；表单内联错误保留在表单内。
- 桌面通知：`Notification.requestPermission()` 仅对 Poke/私聊 请求一次授权，页面失焦时才弹系统通知。

---

### F. 键盘快捷键

| 键位 | 作用 | 场景 |
|------|------|------|
| `Ctrl/Cmd + K` | 聚焦频道过滤框 | 全局 |
| `Ctrl/Cmd + 1…9` | 切换服务器标签 | 全局 |
| `Ctrl/Cmd + W` | 关闭当前标签（有确认：仍在连接时） | 全局 |
| `Ctrl/Cmd + M` | 静音切换 | 全局 |
| `Ctrl/Cmd + Shift + M` | Deafen 切换 | 全局 |
| `↑ / ↓` | 频道树内移动选中 | 树聚焦时 |
| `Enter` | 加入选中频道 | 树聚焦时 |
| `Esc` | 关菜单 / 收起过滤 / 取消 PTT 录制 | 分层 |
| `?` | 快捷键速查弹层 | 全局 |

- PTT 录制键流程补「按 Esc 取消」。
- 输入框聚焦时所有单键快捷键失效（修饰键组合除外）。

---

### G. 状态与边界（统一规格）

| 场景 | 表现 |
|------|------|
| 空频道树 | 「连接服务器后显示频道树」+ 引导箭头指向左栏 |
| 空聊天 | 「还没有消息，来说第一句」 |
| WS 断开（网关挂了） | 顶栏品牌区旁红点「网关离线」，全站操作禁用，不进入 TS 重连逻辑 |
| 麦克风权限被拒 | 音频 section 顶部 err 卡：「麦克风被拒绝 → 浏览器地址栏左侧锁形图标中重新允许」+ [重试] |
| 非 HTTPS 访问 | 首次进入顶部 warn 条：「当前非安全上下文，语音不可用 · 部署指南」可关闭（sessionStorage 记住） |
| 频道满员加入失败 | toast err「频道已满」 |
| 昵称被占用 | 内联错误定位到昵称框 |

### H. 无障碍基线

- 所有交互控件 `:focus-visible` 2px accent 外描边（按钮已有，补输入框/菜单/树行）。
- 说话绿点同时配 `aria-live="polite"` 的屏幕阅读器文本（「张三开始说话」节流 2s）。
- 对比度：`--dim`/`--faint` 用于正文处提升到 ≥4.5:1（当前 faint #62666d on #0f1011 ≈ 4.0:1，hint 文本改 dim）。
- `prefers-reduced-motion`：关呼吸点、进度条动画改静态。

## [S3] Plan（优先级）

| 批 | 内容 | 预估 |
|----|------|------|
| **P0** | A1 首屏引导 · A3 表单折叠 · B1 双击加入 · C 语音状态条（含 Deafen）· G 权限/HTTPS 边界 | 核心体验闭环 |
| **P1** | B3 频道过滤 · D 右键菜单升级 · E1 未读 · E2 滚动锁定 · E3 Toast 统一 | 高频效率 |
| **P2** | A2 重连进度条 · B4 回到我的频道 · F 全快捷键 + 速查层 · E3 桌面通知 · H 无障碍打磨 | 专业感 |

验收标准：P0 完成后，新用户 10 秒内能进频道开麦；老用户全程鼠标不误触切频道；语音上行状态任意时刻一眼可辨。

## 修订（2026-09-12 反馈）

**麦克风显示抖动修复（C 区）**

问题：电平条按 60fps 重绘导致视觉抖动；状态条整条背景跟随 VOX 门限开合闪烁。

- `mic.ts`：电平上报节流到 ~20fps（50ms）且仅当变化 ≥0.02 或门限变化时 setState
- 上行状态加滞回：开启即时，关闭延迟 400ms（`uplink` 去抖），消除门限附近频闪
- 整条背景闪 → 改为左缘 2px talk 竖条 + 柔光，opacity 250ms 过渡
- 麦克风显示重做：圆形按钮 + 电平环（`conic-gradient` + mask 描边环），静音/闭麦转红并加斜杠图标；emoji 换内联 SVG（麦克风/耳机）
- 电平条低通滤波（0.72/0.28）平滑，填充色由 `--dim` 平滑过渡到 `--talk`
- 重复信息清理：连接后隐藏顶栏麦克风 badge（底部状态条已承载），静音按钮与麦克风按钮合并为一处
